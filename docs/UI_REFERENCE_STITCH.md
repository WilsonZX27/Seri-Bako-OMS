# Seri Bako OMS Stitch UI Reference

These screenshots are the current UI source of truth for the OMS redesign direction.

The goal is not to copy pixel-perfect, but to follow the UX logic:

- Left sidebar is simple module navigation.
- Center workspace is for data/content only.
- Right operation console is where actions live.
- UI must be compact, small, minimal, and easy to scan.
- Do not expose workflow states as sidebar items.
- Do not scatter buttons across the page.
- Do not create oversized cards or large empty spaces.
- Reduce scrolling.
- Body text should be around 12px.
- Page title should be around 16–18px.
- Buttons should be compact.
- Tables should be dense but readable.
